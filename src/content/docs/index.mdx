## Install MAESTRO UI

Check the [MAESTRO UI releases](https://github.com/AIRI-MAESTRO/maestro-ui/releases) for a build for your system. If one is available, download and extract the archive. On macOS, move `Maestro.app` to Applications and open it.

<details>
<summary>Run from source</summary>

Install Git, Python 3.12 or 3.13, [uv](https://docs.astral.sh/uv/), Node.js and pnpm. The commands below install the app, build the agent runtime and open the MAESTRO UI window.

```bash
git clone https://github.com/AIRI-MAESTRO/maestro-ui.git
cd maestro-ui
uv sync --extra desktop
git clone https://github.com/deepseek-ai/deepseek-harness ../deepseek-harness
git -C ../deepseek-harness checkout dd6322d604e00eec1ba5e0c8541159906a21094a
pnpm -C ../deepseek-harness install --frozen-lockfile
pnpm -C ../deepseek-harness run build
uv run maestro app --dsh-source ../deepseek-harness
```

</details>

## Build your first agent

1. Choose a project folder. In **Settings → Chat model**, select a provider, enter its API key and choose a model.
2. Start a session and give the agent a task and an example: “Build an agent that extracts the total and currency from a receipt. For ‘Total: $4.50 USD’, I expect an amount of 4.50 and a currency of USD.”
3. Answer any follow-up questions and confirm the build. Ask the agent to run on a different receipt and check the result in the chat.

## Install the agent skill

Give Claude Code, Codex, hermes, or OpenClaw the Maestro skill in one command:

```bash
uvx maestro-install skill        # asks which agent; or --agent claude | codex | hermes | openclaw | all
```

It downloads and unpacks the skill into the agent's skills directory:

- Claude Code → `~/.claude/skills/maestro`
- Codex → `~/.codex/skills/maestro`
- hermes → `~/.hermes/skills/maestro`
- OpenClaw → `~/.openclaw/skills/maestro`

More: [Agent Skill](care/skill/overview/) · [Install & Use](care/skill/install/).
