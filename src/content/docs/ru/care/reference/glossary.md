| Термин | Значение |
| --- | --- |
| **Maestro** | Продукт: настольное приложение (а также TUI и CLI) для генерации, запуска, исправления, сохранения и эволюции агентных цепочек. |
| **Maestro desktop app** (приложение Maestro) | Основной интерфейс: нативное окно вокруг харнесса Maestro. Запуск: `maestro` или `Maestro.app`. |
| **Maestro harness** (харнесс Maestro) | Постоянный агент в чате внутри приложения: сессии, выбор модели, инструменты, подтверждения, фоновые задачи. |
| **`maestro-care`, `care`** | Python-пакет и его имя для импорта. `care` также псевдоним команды `maestro`. CARE — Collaborative Agent Reasoning Ecosystem. |
| **Session** (сессия) | Один разговор в рабочей папке. Ей принадлежат сгенерированные цепочки, запуски и подтверждения. |
| **Chat model** (модель чата) | Модель, выбранная в сессии. В приложении она выполняет генерацию, запуск, исправление, генерацию данных, черновики и перевод идей. |
| **Strategy** (стратегия) | Как агент обрабатывает запрос о цепочке: прямой ответ, повторное использование сохранённой цепочки, генерация, написание цепочки агентом или артефакт из сессии. |
| **Chain** (цепочка) | Программа CARL из типизированных шагов с зависимостями. MAGE её генерирует, CARL выполняет. |
| **Artifact** (артефакт) | Точная цепочка или вход, подготовленные в сессии и закреплённые по SHA-256. Запуски и эволюция используют артефакты, а не «что-то текущее». |
| **Input contract** (входной контракт) | Схема входа, которую объявляет цепочка. Вход проверяется по ней до запуска. |
| **Repair** (исправление) | Предложенная исправленная цепочка после неудачного запуска. Сама не запускается, исходная не меняется. |
| **Library** (Библиотека) | Панель приложения с сохранёнными цепочками, карточками памяти, идеями, наборами данных, инструментами и навыками. |
| **Chain card** (карточка цепочки) | Сохранённая цепочка в Библиотеке: граф структуры, переименование, эволюции, действия Запустить / Эволюционировать / Данные. |
| **Draft request** (черновик запроса) | Текст, который действие Библиотеки кладёт в поле ввода сессии. Вы проверяете и отправляете его; из панели ничего не запускается. |
| **Activity** (Активность) | Панель приложения со списком работы Maestro по всем сессиям. |
| **Full access** (Полный доступ) | Режим сессии, который никогда не спрашивает; платная работа Maestro идёт без окна. |
| **Paid work** (платная работа) | Действия, вызывающие модель: генерация, запуск, исправление, запуск эволюции, запуск генерации данных, черновики, перевод идей. Одно подтверждение на каждое. |
| **Background job** (фоновая задача) | Генерация, запуск, исправление или эволюция, перенесённые в список задач харнесса. Теряются при перезапуске. |
| **CARL** | Исполнитель и формат цепочек. См. [CARL](/ru/carl/getting-started/overview/). |
| **MAGE** | Генератор, превращающий задачу в цепочку CARL. |
| **GigaEvo Memory** | Хранилище цепочек, карточек памяти, инструментов и навыков. |
| **IdeaL** | Озеро идей в GigaEvo Memory: идеи по пространствам с рейтингом по итогам эволюции. См. [IdeaL](/ru/ideal/getting-started/overview/). |
| **Namespace** (пространство) | Пространство IdeaL, которое Maestro читает и пишет (`CARE_MEMORY__IDEAL_NAMESPACE`). |
| **Idea** (идея) | Конкретное переиспользуемое изменение цепочки для мутаций эволюции. Архивируется, не удаляется. |
| **Radar** (радар) | Вид одного прогона эволюции в IdeaL: идеи вокруг задачи, их эффект, кривая лучшего результата, идеи против контроля. |
| **Evolution platform** (платформа эволюции) | GigaEvo Platform: мутирует цепочки и оценивает их на наборе данных. |
| **Evolution data / benchmark factory** (данные для эволюции / фабрика бенчмарков) | Генератор проверенных наборов данных для эволюции в Maestro. Версии называются `bf_<hex>.v<N>`. |
| **Search part / holdout** (поисковая часть / закрытая часть) | Часть набора, которая уходит в эволюцию / скрытая часть, которая остаётся в локальном хранилище. |
| **Workshop** (мастерская) | Черновик → проверки → сохранение для инструментов и навыков. |
| **Tool** (инструмент) | Функция на Python, которую вызывает шаг цепочки. |
| **AgentSkill** (навык) | Переносимая папка с `SKILL.md`, которую может запустить шаг цепочки. См. [Возможности](/ru/care/capabilities/overview/). |
| **Sandbox** (песочница) | Где выполняются скрипты навыков и сгенерированный код. По умолчанию Docker. |
| **STARM solver** (решатель STARM) | Небольшая обученная модель для алгоритмической задачи, доступная как инструмент. См. [Решатели STARM](/ru/care/solvers/starm/). |
| **`chain_id`** | Id, под которым цепочка сохранена в Memory. |
| **Version, channel** (версия, канал) | У сохранённых сущностей неизменяемые версии; каналы (`latest`, `stable`) указывают на версии. |
| **`memory_card`** (карточка памяти) | Сохранённая заметка или сводка запуска в Memory. |
| **Interactive mode** (режим Interactive) | Режим TUI (по умолчанию, бывший Ad-Hoc): генерация, вопрос перед запуском, ответ; сохранение и эволюция кнопками. |
| **Ad-Hoc** | Прежнее имя Interactive. `ad_hoc` по-прежнему читается как `interactive`. |
| **Production mode** (режим Production) | Режим TUI: генерация, сохранение, базовый прогон, эволюция; следующие запросы правят сохранённую цепочку. |
| **Stage policy** (политика этапа) | Поведение этапа в TUI: `ask`, `auto` или `skip` (`CARE_CHAT__MODE__<MODE>__<STAGE>`). |
| **Dataset (eval cases)** (набор данных TUI/CLI) | Тестовые примеры цепочки в TUI/CLI, хранятся как карточки памяти (`maestro dataset`, `/dataset`). Отдельно от данных для эволюции. |
| **Lineage** (родословная) | Происхождение цепочки (`maestro lineage`). |
| **Fitness** | Оценка цепочки-кандидата на наборе данных. |
| **Preflight** | Статическая проверка до запуска (`maestro validate`). |
| **Agent hub** (хаб агентов) | Локальный процесс, обслуживающий развёрнутые цепочки как HTTP-агентов (`/deploy`, `maestro deploy`). |
| **Catalog** (каталог) | Установленные навыки, MCP-серверы, инструменты и карточки памяти (`maestro catalog`, `Ctrl+K` в TUI). |
