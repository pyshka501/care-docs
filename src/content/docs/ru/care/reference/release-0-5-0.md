Релиз 0.5.0 — общий выпуск документации для стека: Maestro, CARL 0.5.0, MAGE
и IdeaL. В этом релизе основной интерфейс — **приложение Maestro**. TUI и CLI
остаются поддерживаемыми дополнительными интерфейсами.

## Приложение и харнесс Maestro

- `maestro` (без подкоманды) и `Maestro.app` открывают приложение: нативное
  окно вокруг харнесса Maestro, постоянного агента в чате с сессиями,
  инструментами, подтверждениями и фоновыми задачами. `maestro tui`
  открывает TUI.
- **Одна модель.** Генерация, запуск, исправление, генерация данных для
  эволюции, черновики мастерской и перевод идей используют модель чата
  сессии. Ключ провайдера остаётся в харнессе. Отдельный ключ не
  подставляется.
- **Стратегии.** Агент планирует каждый запрос о цепочке: повторно
  использовать сохранённую, сгенерировать новую (по умолчанию), поручить
  агенту написать её или взять артефакт из сессии.
- **Запуски.** Пауза, продолжение и остановка между шагами; предложения
  исправлений, которые сами не запускаются; фоновые задачи для долгой
  работы.

См. [Приложение](/ru/care/app/overview/).

## Библиотека

Панель в боковой панели, которая открывается без сессии и без вызова
модели: цепочки, карточки памяти, идеи, наборы данных для эволюции,
инструменты и навыки. Карточка цепочки показывает граф структуры,
переименовывает цепочку новой версией и перечисляет её прогоны эволюции с
радаром. Действия Запустить, Эволюционировать и Данные кладут в сессию
готовый запрос, который вы проверяете и отправляете. Панель называет память,
которую читает, и подсказывает, что исправить, если та не отвечает.
См. [Библиотека](/ru/care/app/library/).

## Активность

Единый список генераций, запусков, исправлений, эволюций и генераций данных
из всех сессий, с прогрессом и причинами ошибок простыми словами. Если IdeaL
включён, в списке есть и прогоны эволюции, которые хранит IdeaL. Они видны
после перезапуска. См. [Активность](/ru/care/app/activity/).

## Меньше подтверждений

- Платная работа спрашивает **один раз**, в окне приложения. Агент не
  спрашивает в чате.
- Бесплатные действия (сохранение, переименование, отмена, пауза, архив
  идеи, подсказка идеи) проходят без окна.
- Сессия в режиме **Полный доступ** никогда не спрашивает.
- Нажатие кнопки в собственных формах Maestro (генерация данных, мастерская,
  форма идеи) считается согласием.

См. [Подтверждения](/ru/care/app/confirmations/).

## Идеи IdeaL и радар

Когда память цепочек — IdeaL: выборка для генерации из каталога IdeaL,
цепочки в вашем пространстве, а прогоны эволюции берут подборки идей из IdeaL
и возвращают результаты под постоянным ключом задачи. В приложении: граф
идей; добавление, правка, архивирование и возврат идей с проверкой похожих
и переводом на английский; **радар** прогона (идеи вокруг задачи, их эффект,
идеи против контроля); подсказка идеи в идущую эволюцию. Агент в приложении
может и наполнить идеи для задачи, показав их вам на проверку до
сохранения. См. [Идеи и радар IdeaL](/ru/care/app/ideas/) и
[IdeaL](/ru/ideal/getting-started/overview/).

## Русский интерфейс

Русский языковой пакет для оболочки харнесса (около тысячи строк);
собственные панели Maestro на русском. Страница настроек MAESTRO остаётся на
английском. См. [Настройки и язык](/ru/care/app/settings/).

## Генерация данных для эволюции

Генератор проверенных наборов данных для цепочки: бюджет токенов, пауза,
повторы, инструкции на ходу, версии набора со скрытой закрытой частью и
передача в эволюцию одной кнопкой.
См. [Данные для эволюции](/ru/care/workflows/data-generation/).

## Мастерская инструментов и навыков

Создание и переработка инструмента или навыка: черновик, проверки
(инструменты запускаются на примерах в песочнице Docker), сохранение новой
версией. См. [Мастерская инструментов и навыков](/ru/care/workflows/workshop/).

## Решатели STARM

Алгоритмические подзадачи (судоку, лабиринты, арифметические головоломки,
«Жизнь», ARC-AGI) можно отдавать обученным моделям-решателям как встроенным
инструментам, с локальной проверкой ответа, где задача это позволяет. См.
[Решатели STARM](/ru/care/solvers/starm/).

## CARL 0.5.0

Цепочки выполняются на CARL 0.5.0. См.
[журнал изменений CARL](/ru/carl/reference/changelog/).

## TUI и CLI

- Режим TUI **Ad-Hoc** теперь называется **Interactive**. Он спрашивает
  перед запуском цепочки; `ad_hoc` по-прежнему принимается. См.
  [режимы](/ru/care/workflows/modes/).
- Команда CLI — `maestro`; `care` остаётся псевдонимом.

## Известные ограничения

- `Maestro.app` только под macOS arm64, подписан ad-hoc и не нотаризован.
- Фоновые задачи, список Активности в процессе, пауза цепочки и владение
  запуском не переживают перезапуск приложения.
- Прогоны эволюции можно отменить, но не поставить на паузу. Общий бюджет
  токенов — проверка при планировании, платформа ограничивает токены на
  каждый вызов.
- Наборы *задач с инструментами* пока нельзя использовать для эволюции.
- Лучшая цепочка эволюции не сохраняется в память автоматически.
- Блок *Chain generation* на странице настроек MAESTRO не влияет на генерацию
  в приложении (кроме режима), хотя заголовок страницы говорит обратное.
- Вызовы из собственных форм Maestro распознаются по идентификатору. Можно
  ли подделать такой идентификатор через собственный endpoint модели, ещё
  проверяется.
