CARE — пользовательский интерфейс на вершине стека из четырёх модулей. Каждый
модуль отвечает за один этап жизненного цикла агента.

```text
                    ┌──────── GigaEvo Memory ────────┐  (save / load)
                    ▼                                 │
You → CARE → MAGE ──generate──▶ CARL ──result──▶ CARE ┘
                                                 │
                                                 └──evolve──▶ GigaEvo Platform ──winner──▶ Memory
```

| Модуль | Пакет | Этап | Роль |
| --- | --- | --- | --- |
| **MAGE** | `mmar-mage` | Генерация | Превращает задачу на естественном языке в CARL-цепочку. |
| **CARL** | `mmar-carl` | Исполнение | Запускает цепочку — параллелизм DAG, инструменты, память, мульти-агенты. См. [документацию CARL](/ru/carl/getting-started/quick-start/). |
| **GigaEvo Memory** | `gigaevo-client` | Персистентность | Хранит сущности (chain / agent / agent_skill / memory_card), библиотеку, историю запусков. |
| **GigaEvo Platform** | — | Эволюция | Генетический поиск по цепочкам; принять победителя и продвинуть его. |

## Жизненный цикл

1. **Генерация** — вы описываете задачу; MAGE планирует CARL-цепочку.
2. **Исполнение** — CARL запускает цепочку и возвращает результат (с трассировкой токенов и стоимости).
3. **Персистентность** — в режиме Production CARE сохраняет цепочку в Memory под
   стабильным `chain_id` и записывает каждый запуск.
4. **Эволюция** — опционально Platform запускает генетический алгоритм над цепочкой, и вы принимаете
   лучшую особь обратно в стабильный канал.

## Канонический сценарий

Сгенерировать агента A → сохранить → сгенерировать B и C → вернуться к A из
[Библиотеки](/ru/care/tui/screens/) → перезапустить с той же задачей и файлами контекста →
опционально эволюционировать A и принять лучшую особь в стабильный канал.

## Плавная деградация

CARE импортирует каждый вышестоящий модуль **лениво** — внутри функции, которой он нужен.
Поэтому минимальная установка по-прежнему запускает CLI и TUI; отсутствующий компонент (например,
опциональный экстра `care[carl]` или ненастроенный URL Memory) выдаёт понятную подсказку,
а не сбой. Без настроенной Memory режим Production автоматически откатывается в
[Ad-Hoc](/ru/care/getting-started/overview/).
