TUI на Textual — поддерживаемый дополнительный интерфейс Maestro. Основной
интерфейс — [приложение](/ru/care/cli/app/). TUI нужен для работы в терминале, по
SSH и на машинах без рабочего стола. Оба читают один конфиг и одну Memory.

```bash
maestro tui
```

`maestro` без подкоманды открывает приложение, а не TUI. TUI сразу открывается в
**чате**: транскрипт, поле ввода внизу и переключатель режима над ним.

## Чат

- **Напишите задачу** обычными словами. Генератор соберёт цепочку, среда исполнения
  её запустит, ответ появится в транскрипте.
- **Наберите [slash-команду](/ru/care/slash-commands/overview/)** (`/help`,
  `/library`, …) для всего остального. После `/` появится список подсказок.
- **Переключатель режима** меняет [Interactive ↔ Production](/ru/care/workflows/modes/).
  По умолчанию Interactive: перед запуском цепочки он спрашивает (запуск сразу
  включается в `/settings`) и ничего не сохраняет без вас. Production сохраняет
  каждую цепочку в Memory, делает базовый запуск и, если настроена Platform,
  запускает эволюцию. Без Memory Production возвращается в Interactive.
- **Посмотрите цепочку** за ответом: кнопка **View chain** открывает
  [DAG цепочки](/ru/care/tui/dag/), а **плашка Artifacts** собирает всё, что
  появилось в чате.
- Новичкам предлагается набрать `/tour`, обзор из 5 шагов.

### Как идёт запуск

Пока цепочка генерируется и исполняется, в транскрипте видна **цепочка этапов**:
строки `▶ Этап…`, которые завершаются `✓`, с подстроками `⎿` для деталей. Строка
состояния показывает расход токенов. В режиме Production после успешной генерации
автоматически идут сохранение, базовый запуск и, если настроено, эволюция.

### Файлы

Ссылайтесь на файлы прямо в тексте через `@<путь>`, например
`summarise @report.pdf`. После `@` появляется подсказка по файлам. Из PDF
извлекается текст, изображения встраиваются для моделей со зрением. Пути с
пробелами берите в кавычки: `@"My Notes.md"`.

## Глобальные клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl+P` | Палитра команд (нечёткий поиск по командам и сохранённым сущностям). |
| `Ctrl+K` | Каталог возможностей (навыки / MCP / инструменты). |
| `Ctrl+B` | Панель задач (работающие воркеры). В чате `Ctrl+B` вместо этого копирует первый блок кода из последнего ответа. |
| `?` | Справка: туториал и все привязки активного экрана. |
| `Ctrl+S` / `Ctrl+R` | Сохранить / перезапустить текущий артефакт, где экран это поддерживает. |
| `Esc` | Назад. |
| `Ctrl+C` | Выход. `Ctrl+Q` тоже выходит, кроме чата: там он цитирует последний ответ. |

У каждого экрана свои привязки. Нажмите `?`, чтобы увидеть привязки текущего
экрана, или выполните в оболочке `maestro help --screen <ScreenName>`.

## Чего нет в TUI

Резидентный агент, работа с идеями IdeaL (засев, радар запуска, принудительная
идея), мастерская инструментов, генерация бенчмарков и строгий режим решателей
STARM есть только в приложении. TUI использует ту же Memory, поэтому цепочки,
сохранённые в приложении, видны в библиотеке TUI.
