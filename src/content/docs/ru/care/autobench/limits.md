Автобенчмарк живёт в ветке разработки и в выпущенную сборку не входит. У
каждого пункта ниже пометка:

- **вживую**: запускалось на настоящей модели;
- **тесты**: покрыто автотестами с подставной моделью или подставным
  бинарём;
- **не проверено**: ни то ни другое либо только прочитано в коде.

## Статус

| Что | Статус | Источник |
| --- | --- | --- |
| Свободный ответ с проверкой судьёй | **вживую**: принято 6 из 7 (Codex `gpt-6-luna`) | сообщение коммита ветки, 2026-11-02 |
| Числовые ответы (суммы чеков) с добором | **вживую**: принято 14 при цели 8 | там же |
| Программа-генератор | **вживую**: принято 10 из 10, аудит 7 из 8 | там же |
| Картинки на входе (фото чеков) | **вживую**: принято 5 из 6 | там же |
| Пауза, продолжение, инструкции, остановка, восстановление после перезапуска, версии, **Использовать для эволюции** | **вживую** на более ранней сборке того же движка (модель чата, 2026-09-28); на сгенерированной версии прошла одна эволюция | журнал разработки |
| Закрытая часть не уходит в эволюцию, её эталоны не возвращаются | **тесты** и манифест версии | журнал разработки |
| Остановка по бюджету и по вызовам, планирование добора, стоп без прогресса | **тесты** | юнит-тесты |
| Правка, пропорции, сохранение версий | **тесты** | юнит-тесты |
| Песочница генератора: без сети и без записи в домашнюю папку | **тесты** | юнит-тесты |
| Проверка файлов по сигнатуре и месту | **тесты** | юнит-тесты |
| Форма вызова Codex (`--output-schema`, последнее сообщение) | **тесты** с подставным бинарём | юнит-тесты |
| Правила подтверждения для каждого инструмента | **тесты** | тесты политики |
| Задачи с инструментами | **вживую** QA нашёл неподтверждённые задания, когда падал один вызов решателя; исправление (параллельные куски с одним повтором) покрыто **тестами** | сообщение коммита ветки |
| Импорт из CSV/TSV/XLSX | **тесты** | юнит-тесты |
| Собранное приложение из этой ветки | **не проверено** | — |
| Программы-генераторы внутри собранного приложения (системный `/usr/bin/python3`) | **не проверено** | — |
| PDF, DOCX, XLSX, CSV и аудио на входе | **не проверено** (вживую шли только картинки) | — |
| Догенерация с Codex | **не проверено** | — |
| Эволюция на наборе с критерием судьи от начала до конца | **не проверено** | — |

## Известные пробелы

**Проверка**

- Слепой решатель и судья используют тех же провайдера и модель, что и
  генератор. Общие ошибки проходят незамеченными.
- Спецификацию не показывают на утверждение: генерация начинается сразу
  после неё. Направляйте инструкциями или правьте примеры потом.
- В процессах с программой-генератором инструкции не применяются (по коду).
  Меняйте программу на вкладке **Генератор**.
- В версиях от старых сборок могут быть примеры, принятые с уровнем
  `executable` (эталон не подтверждён), и такие версии всё равно предлагаются
  для эволюции. Смотрите счётчики уровней у версии.

**Эволюция**

- Используется только поисковая часть. Ни один инструмент не сравнивает
  победителя с исходной цепочкой на закрытой части, и ничего не продвигается
  в память само.
- Платформа эволюции оценивает 2 строки обучения и 1 строку валидации за
  оценку (по коду). См.
  [Сколько строк реально оценивает эволюция](/ru/care/autobench/evolution/#сколько-строк-реально-оценивает-эволюция).
- Наборы с файлами и с задачами на инструменты в эволюцию не отдать.
- Число с допуском 0 на платформе превращается в сравнение текста.
  Регулярное выражение с маркером может поставить ноль любому кандидату (по
  коду). См.
  [Как проверка становится оценщиком эволюции](/ru/care/autobench/checks/#как-проверка-становится-оценщиком-эволюции).
- Наборам с критерием судьи нужна сборка платформы эволюции с LLM-судьёй.

**Расход**

- Бюджет проверяется между пакетами, поэтому уже начатые пакеты могут вывести
  итог за бюджет.
- Токены Codex считаются по оценке CLI.
- В живых прогонах примерно половина пакетов с картинками вернулась без
  годного файла. Такие пакеты повторяются, и повторы стоят токенов.
- **Догенерировать недостающие N (платно)** на экране не увеличивает бюджет;
  процесс, который его уже потратил, сразу снова закончится.

**Прочее**

- Программы-генераторы изолируются через `sandbox-exec` macOS. Где его нет,
  они запускаются без него (изолированный Python, минимальное окружение).
- Импортированные таблицы помнит только работающий процесс сессии (последние
  16) и в **Наборах данных** их нет.
- Файлы на входе создаёт только Codex.
