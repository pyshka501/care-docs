Всё на этой странице, кроме **догенерации** и **просьбы к модели изменить
генератор**, работает без вызовов модели и бесплатно. Можно делать это и во
время генерации, и после.

## Примеры

Вкладка **Примеры** делит примеры на **Принятые**, **Отклонённые**, **Без
проверки**, **Исключённые** и **Устаревшие**; есть фильтр по семейству и
поиск по входу и эталону. У каждого примера видны семейство, сложность,
часть, [уровень проверки](/ru/care/autobench/checks/#уровни-проверки),
эталон, ответ слепого решателя (если он другой) и причины отказа.

Примеры закрытой части в списке есть, но эталон скрыт: «Эталон закрытой
части скрыт».

| Кнопка | Что делает |
| --- | --- |
| **Изменить** | Правка полей входа, эталона, допустимых альтернатив (по одной в строке) или части набора. **Сохранить (проверено мной)** делает пример принятым с уровнем `manual`. Сам сгенерированный файл здесь не правится. У примера закрытой части старый эталон остаётся скрытым: впишите новый, чтобы заменить. |
| **Принять как есть** | Для отклонённых, непроверенных и устаревших. Уровень `manual`. |
| **Исключить** / **Вернуть** | Убрать из набора с сохранением истории. При возврате проверки идут заново. |
| **В закрытую часть** / **В поисковую часть** | Перенести принятый пример между частями. |
| **Добавить пример** | Свой пример: семейство, поля входа, эталон, альтернативы, часть. Принимается с уровнем `manual`. Дубликат существующего не примется. |

То, что вы написали или приняли, проверяете вы: Maestro ручные примеры
заново не проверяет.

## Пропорции

Вкладка **Пропорции** собирает версию набора из принятых примеров. Для
каждого семейства видно долю (ползунок), сколько примеров **Есть**, сколько
**Нужно**, сколько **Не хватает** и **Часть** (поиск или закрытая).

- **Размер версии**: 0–5000; по умолчанию все принятые.
- **Поровну** выставляет равные доли, **Как есть** возвращает текущее
  распределение.
- Часть семейства, выбранная здесь, меняется только в сохраняемой версии.
- Если из семейства берётся не всё, сначала идут примеры с более надёжной
  проверкой: ручные, потом подтверждённые решением, подтверждённые судьёй
  после спора, проверенные судьёй.

Превью пересчитывается на ходу. **Сохранить версию набора** записывает новую
версию; в её происхождении отмечено, что состав задан вручную.

### Догенерация

Если в семействе не хватает примеров, на вкладке появляется кнопка:

- **Догенерировать недостающие N (платно)** для наборов, которые пишет
  модель. Процесс *дополняется*: новые пакеты только в недобранные семейства,
  до 200 примеров на семейство за раз, цель поднимается на это число.
  Доступно для завершённого, остановленного, упавшего, приостановленного или
  ждущего процесса. Прогресс виден на **Обзоре**. Бюджет кнопка не
  увеличивает: если процесс уже его израсходовал, он сразу снова
  закончится с причиной «достигнут бюджет» (по коду). Тогда попросите агента
  дополнить процесс с добавкой токенов (`extra_tokens`).
- **Сгенерировать недостающие N (бесплатно)** для программы-генератора.
  Программа работает локально, без модели.

С экрана окно подтверждения не появляется. Если дополнить процесс просит
агент, приложение спросит: это новые платные вызовы, и бюджет может вырасти.
См. [Инструменты агента](/ru/care/autobench/tools/).

## Версии

Вкладка **Версии** показывает версии набора, новые сверху. У каждой видны id
(`bf_<16 hex>.v<N>`), дата, число примеров в поисковой и закрытой части,
проверка, число ручных правок, задан ли состав вручную и сколько примеров на
каждом уровне проверки.

Версия сохраняется сама в конце процесса и по кнопке **Сохранить версию
набора**. Повторное сохранение того же содержимого новую версию не создаёт.

Кнопка **Использовать для эволюции** есть, когда на версии можно запускать
эволюцию. См. [Набор в эволюции](/ru/care/autobench/evolution/).

## Код генератора

Для наборов из режима **Модель пишет генератор** вкладка **Генератор**
показывает программу, её версию и кто её написал: модель или вы.

| Действие | Цена |
| --- | --- |
| Править код, **Проверить на 10 примерах** | Бесплатно: запуск в локальной песочнице, таблица превью и проблемы. |
| **Сохранить код** | Бесплатно: новая версия программы, автор вы. |
| Попросить модель изменить, **Изменить (1 вызов)** | Один вызов модели. Новый код показывается с превью; чтобы оставить его, сохраните. |
| **Сколько примеров добавить** → **Сгенерировать** | Бесплатно. Недоступно, пока есть несохранённые правки. |

Сгенерированные примеры всё равно проходят программные проверки. Пока
процесс работает, генерировать ещё нельзя.
