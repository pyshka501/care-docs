В чате [TUI](/ru/care/tui/overview/) всё, что **не** начинается с `/`, уходит
генератору цепочек как задача. Slash-команды — остальные действия: открыть экран,
управлять сессией, переключить режим, работать с библиотекой и agent hub.

В TUI зарегистрировано 44 команды. Все работают в обоих режимах. `/help`
показывает подборку под текущий режим: в Production вместо строки `/evolution`
выводятся подкоманды датасета, upload, forget и эволюции (см.
[Команды Production](/ru/care/slash-commands/production/)). Наберите `/`, и
появится подсказка с описанием каждой команды.

:::tip
`/help` печатает обзор режимов и список команд текущего режима. `/tour` запускает
обзор из 5 шагов. `maestro help --commands` показывает, у каких slash-команд есть
аналог в CLI.
:::

## Основные

| Команда | Что делает |
| --- | --- |
| `/help` | Обзор режимов и список команд. |
| `/tour` | Обзор из 5 шагов (аргументы игнорируются). |
| `/mode [interactive\|production]` | Показать или переключить [режим чата](/ru/care/workflows/modes/). Понимает также `chat`, `agent`, `prod` и старое `ad-hoc`. |
| `/settings` | Открыть настройки. |
| `/status` | Отчёт о состоянии генератора цепочек, Memory и Platform. |
| `/new` | Новый разговор Interactive (контекст сбрасывается). |
| `/clear` | Очистить транскрипт. |
| `/quit` · `/exit` | Выйти из Maestro. |

## Цепочки и библиотека

| Команда | Что делает |
| --- | --- |
| `/artifacts` | Цепочки, созданные в этом чате. |
| `/library` | Библиотека сохранённых цепочек. |
| `/run <chain_id>` | Открыть сохранённую цепочку на экране Inspection для запуска. |
| `/revise <id> <change>` | Правка цепочки с помощью ИИ: предпросмотр diff, после подтверждения новая версия. `/revise <change>` находит цепочку по вашим словам. |
| `/versions <id\|name> [diff <vA> <vB>]` | История версий с указателями каналов; `diff` показывает JSON-патч между версиями. |
| `/rollback <id\|name> [--channel stable] [--to <version-id>]` | Перевести канал на версию назад или на указанную. Ничего не удаляется. |
| `/promote <id\|name> [--from latest] [--to stable] [--force]` | Релиз с проверкой, см. [Команды Production](/ru/care/slash-commands/production/). |
| `/marketplace [query]` | Маркетплейс `agent_skill`. |
| `/evolution` | Вводная по эволюции, затем панель запусков. |

## Agent hub

| Команда | Что делает |
| --- | --- |
| `/deploy <id\|name> [--channel stable] [--name x]` | Развернуть цепочку как HTTP-агента со своей страницей Swagger. |
| `/deployments [undeploy\|reload\|docs <name>]` | Список агентов на hub, либо снять, перезагрузить агента или открыть его документацию. |
| `/metrics` | Использование и стоимость в USD по агентам. Только чтение. |

Подробнее: [Деплой агентов](/ru/care/workflows/deploy/).

## Память и контекст

| Команда | Что делает |
| --- | --- |
| `/memory [show\|forget <key>\|edit]` | Показать `CARE.md` и долговременную память, удалить один ключ или открыть `CARE.md` в редакторе. |
| `/remember <text>` | Сохранить заметку в долговременную память; модель сливает её с устаревшими фактами. То же делает сообщение, начинающееся с `#`. |

## Сессия и транскрипт

| Команда | Что делает |
| --- | --- |
| `/resume [latest\|<file>]` | Список недавних сессий или восстановление последней либо указанной. |
| `/sessions [latest\|<id>]` | Список сохранённых сессий артефактов или восстановление одной. |
| `/history [N]` | Недавние запросы и сохранённые цепочки. |
| `/edit [N\|list]` | Заново отредактировать прошлый запрос (нумерация с 1). |
| `/multi` | Редактор многострочной задачи. |
| `/branch [name\|list\|switch <id>\|delete <id>]` | Сохранить, показать, переключить или удалить контрольные точки транскрипта. |
| `/blocks [copy <N>\|save <N> <path>]` | Показать, скопировать или сохранить блоки кода. |
| `/export <md\|mdx\|json\|html> [path]` | Сохранить транскрипт на диск. |

## Диагностика и интерфейс

| Команда | Что делает |
| --- | --- |
| `/cost` | Панель токенов и расходов. |
| `/runs` | Локальная история запусков (`~/.cache/care/runs`). |
| `/logs` · `/log [level] [module]` | Открыть просмотр логов или вывести хвост лога в чат. |
| `/profile` | Профили учётных данных. |
| `/sandbox` | Проверить и отозвать доверенные AgentSkills. |
| `/subagents [clear]` | Дерево событий шагов цепочки. |
| `/theme [name]` | Список тем или переключение. |
| `/imgpreview [status\|<path>]` | Проверить поддержку графики в терминале или собрать последовательность изображений. |
| `/voice [status\|transcribe <path>]` | Состояние Whisper или расшифровка аудиофайла. Нужны дополнительные зависимости для голоса. |

## Жизненный цикл Production

| Команда | Что делает |
| --- | --- |
| `/dataset list\|add\|run\|export …` | Датасет цепочки: ведение и оценка. |
| `/upload <chain_id>` | Отправить цепочку POST-запросом на `CARE_UPLOAD__URL`. |
| `/forget <chain_id> [--force]` | Мягко удалить цепочку и её датасет (без `--force` только предпросмотр). |

`/help` показывает их в режиме Production, см.
[Команды Production](/ru/care/slash-commands/production/).
