**Maestro** — настольное приложение для сборки агентных цепочек. Вы
описываете задачу в чате. Maestro генерирует цепочку, запускает её на ваших
данных, исправляет после неудачного запуска, сохраняет в память и
эволюционирует на наборе данных.

Цепочка — это небольшая программа из типизированных шагов (вызовы модели,
инструменты, MCP-серверы, навыки) с зависимостями между ними. Цепочки
записываются в [формате CARL](/ru/carl/getting-started/overview/).

## Интерфейсы

| Интерфейс | Команда | Статус |
| --- | --- | --- |
| **Приложение Maestro** | `maestro` (или `maestro app`) | Основной. Нативное окно с агентом в чате, Библиотекой, Активностью и Настройками. |
| Textual TUI | `maestro tui` | Поддерживается, дополнительный. Чат в терминале с режимами Interactive и Production. |
| CLI | `maestro <подкоманда>` | Поддерживается, дополнительный. Скрипты, CI, администрирование памяти. |
| Агентный навык | — | Управление Maestro из другого агента через CLI. См. [Агентный навык](/ru/care/skill/overview/). |

Python-пакет называется `maestro-care`. Его имя для импорта и прежнее имя
команды — `care`. `care` по-прежнему работает как псевдоним `maestro`.

## Что делает приложение

Приложение построено вокруг **харнесса Maestro**: постоянного агента в чате
с сессиями, инструментами, подтверждениями и фоновыми задачами. Работу с
цепочками выполняют типизированные инструменты Maestro, которые агент
вызывает за вас.

- **Генерация** цепочки по описанию задачи. Можно поручить агенту написать её
  самому.
- **Запуск** цепочки на ваших данных. Между шагами его можно поставить на
  паузу, продолжить или остановить.
- **Исправление** неудачного запуска: Maestro предлагает исправленную
  цепочку, а её запуск — отдельный шаг.
- **Сохранение** цепочек в память. Потом их легко найти в
  [Библиотеке](/ru/care/app/library/).
- **Генерация данных для эволюции**: проверенный набор данных для цепочки.
- **Эволюция** цепочки на этом наборе на платформе эволюции.
- **Работа с идеями** в [IdeaL](/ru/ideal/getting-started/overview/):
  добавлять идеи, смотреть, какие помогают эволюции, направлять идущую
  эволюцию.
- **Создание инструментов и навыков** в мастерской, с проверками перед
  сохранением.

Все вызовы модели (генерация, запуск, исправление, генерация данных,
черновики) идут в **модель чата, выбранную в сессии**. Платная работа
спрашивает одно подтверждение в окне приложения. См.
[Подтверждения](/ru/care/app/confirmations/).

## Стек

| Часть | Роль |
| --- | --- |
| **Maestro** (`maestro-care`) | Приложение, плагины харнесса, CLI и TUI. |
| **MAGE** (`mmar-mage`) | Генерирует цепочку CARL по описанию задачи. |
| **CARL** (`mmar-carl`) | Выполняет цепочки. См. [CARL](/ru/carl/getting-started/overview/). |
| **GigaEvo Memory** с **IdeaL** | Хранит цепочки, карточки памяти, инструменты и навыки. IdeaL хранит идеи и их влияние на эволюцию. |
| **GigaEvo Platform** | Эволюционирует цепочку на наборе данных. |

Подробнее: [Архитектура](/ru/care/concepts/architecture/).
