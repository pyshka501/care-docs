**Maestro** — настольное приложение для сборки ИИ-агентов. Вы описываете
задачу в чате. Maestro уточняет недостающее, собирает агента (цепочку),
проверяет его на ваших примерах, запускает на ваших данных и файлах,
исправляет после неудачного запуска, сохраняет в память, эволюционирует на
наборе данных и может опубликовать как HTTP-сервис.

Цепочка — это небольшая программа из типизированных шагов (вызовы модели,
инструменты, MCP-серверы, навыки) с зависимостями между ними. Цепочки
записываются в [формате CARL](/ru/carl/getting-started/overview/).

## Интерфейсы

| Интерфейс | Команда | Статус |
| --- | --- | --- |
| **Приложение Maestro** | `maestro` (или `maestro app`) | Основной. Нативное окно с агентом в чате, «Моими агентами», панелью IdeaL, «Активностью» и настройками. |
| Textual TUI | `maestro tui` | Поддерживается, дополнительный. Чат в терминале с режимами Interactive и Production. |
| CLI | `maestro <подкоманда>` | Поддерживается, дополнительный. Скрипты, CI, администрирование памяти. |
| Агентный навык | — | Управление Maestro из другого агента через CLI. См. [Агентный навык](/ru/care/skill/overview/). |

Python-пакет называется `maestro-care`. Его имя для импорта и прежнее имя
команды — `care`. `care` по-прежнему работает как псевдоним `maestro`.

## Что делает приложение

Приложение построено вокруг **харнесса Maestro**: постоянного агента в чате
с сессиями, инструментами, подтверждениями и фоновыми задачами. Работу с
цепочками выполняют типизированные инструменты Maestro, которые агент
вызывает за вас.

- **Сборка** агента по описанию. По умолчанию агент чата сам пишет цепочку,
  смотрит реальные ответы API и прогоняет её, генератор MAGE — запасной
  вариант. Перед сборкой он спрашивает недостающее или решает сам и
  перечисляет допущения.
- **Запуск** на ваших данных или прикреплённых файлах (PDF, Word, Excel,
  PowerPoint, текст). Между шагами его можно поставить на паузу, продолжить
  или остановить.
- **Исправление** неудачного запуска: Maestro предлагает исправленную
  цепочку, а её запуск — отдельный шаг.
- **Сохранение** агентов в память. Потом их легко найти в
  [«Моих агентах»](/ru/care/app/library/).
- **Данные для оценки**: импорт файла CSV/XLSX или генерация проверенного
  набора в [студии наборов данных](/ru/care/autobench/overview/).
- **Эволюция** агента на этом наборе на платформе эволюции: по точным
  метрикам, с LLM-судьёй или сразу по нескольким целям (фронт Парето).
- **Работа с идеями** в [IdeaL](/ru/ideal/getting-started/overview/) прямо в
  приложении: засевать идеи, смотреть, какие помогают эволюции, подсказывать
  идею идущей эволюции.
- **Создание инструментов и навыков** в мастерской, с проверками перед
  сохранением.

По умолчанию все вызовы модели идут в **модель чата, выбранную в сессии**. В
настройках работу с цепочками можно перевести на отдельную модель. Платная
работа спрашивает одно подтверждение в окне приложения. См.
[Подтверждения](/ru/care/app/confirmations/).

Многое из этого есть в сборках текущей линии разработки и ещё не вошло в
выпущенный релиз Maestro. Страницы [о приложении](/ru/care/app/overview/)
это помечают.

## Стек

| Часть | Роль |
| --- | --- |
| **Maestro** (`maestro-care`) | Приложение, плагины харнесса, CLI и TUI. |
| **MAGE** (`mmar-mage`) | Генерирует цепочку CARL по описанию задачи (запасной вариант к агенту чата). |
| **CARL** (`mmar-carl`) | Выполняет цепочки. См. [CARL](/ru/carl/getting-started/overview/). |
| **GigaEvo Memory** с **IdeaL** | Хранит цепочки, карточки памяти, инструменты и навыки. IdeaL хранит идеи и их влияние на эволюцию. |
| **GigaEvo Platform** | Эволюционирует цепочку на наборе данных. |

Подробнее: [Архитектура](/ru/care/concepts/architecture/).
