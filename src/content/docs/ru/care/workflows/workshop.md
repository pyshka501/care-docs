Мастерская создаёт новый **инструмент** или **навык** либо перерабатывает
сохранённый в памяти, в три шага: **черновик → проверки → сохранение**.
Откройте её через **Библиотека → Инструменты и навыки** при открытой сессии
или попросите агента в чате.

| | Инструмент | Навык |
| --- | --- | --- |
| Что это | Функция на Python только со стандартной библиотекой. | `SKILL.md`: инструкции, которым следует агент. |
| Проверки | Код разбирается; определяет ровно объявленную функцию; импортирует только стандартную библиотеку; не использует примитивы процессов и `eval`; **запускается на примерах в песочнице Docker**. | Только структурные: frontmatter, имя, тело, отсутствие секретов, только известные инструменты. |
| Что доказывают проверки | Код корректен и вернул результаты на примерах. | Файл корректен. **Не** доказывают, что агент с ним работает лучше. |

## Создание

1. **Создать инструмент** или **Создать навык**.
2. Опишите, что он должен делать, например *«курс валюты на дату по
   публичному API без ключа»* или *«проверять счета: пересчитать позиции и
   найти расхождение»*. По желанию задайте имя, аргументы (для инструмента)
   и требования.
3. **Подготовить черновик**. Это один-два вызова модели чата (платно).
   Нажатие кнопки — ваше согласие, дополнительного окна нет. Если черновик
   готовит агент из чата, приложение спросит один раз.
4. Посмотрите черновик и результаты проверок. **Сделать другой вариант**
   запросит новый черновик.
5. **Сохранить в память**. Это бесплатно и проходит без окна.

Черновик живёт только в памяти приложения и не попадает в хранилище, пока вы
не сохраните его. Черновик с проваленными проверками **сохранить нельзя**.

## Переработка

Выберите сохранённый инструмент или навык и нажмите **Переработать**.
Опишите, что изменить. Для инструмента проверки дополнительно прогоняют
примеры предыдущей версии. Сохранение пишет **новую версию** того же
инструмента или навыка (**Сохранить новой версией**).

## Куда попадает сохранённое

Сохранённые инструменты и навыки попадают в настроенную память. Список
мастерской показывает те, что лежат в этой памяти, с поиском и фильтрами
(все, инструменты, навыки).

## Требования и ограничения

- Для проверки инструментов нужен работающий **Docker**. Код инструмента
  выполняется только в песочнице Docker, никогда в процессе приложения.
- Память только для чтения не даёт сохранять.
- Проверки навыков не измеряют поведение. Проверьте навык, запустив цепочку,
  которая его использует.
