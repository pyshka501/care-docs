Переключатель над промптом (или `/mode`) выбирает один из двух режимов. Они различаются
тем, **что происходит на каждом промпте** и **сохраняется ли что-либо**.

| | **Ad-Hoc** (по умолчанию) | **Production** |
| --- | --- | --- |
| На каждом промпте | Сгенерировать цепочку, выполнить её **на месте**, ответить inline. | Сгенерировать **воспроизводимую** цепочку, сохранить, выполнить baseline, (опционально) эволюционировать. |
| Цикл агента | Может зацикливаться **в стиле ReAct**, пока не решит, что задача выполнена. | **Без цикла** — одна задача → одна воспроизводимая цепочка. |
| Синтез ответа | Когда ≥2 шагов успешны, дополнительный вызов LLM объединяет их в один ответ. | Пропускается — цепочки должны оставаться воспроизводимыми. |
| Сохранение? | **Ничего** не сохраняется. | Сохраняется в Memory под стабильным `chain_id` + запись baseline-датасета. |
| Следующий промпт | Генерирует новую цепочку (переносит историю Ad-Hoc для контекста). | **Итерирует ту же цепочку** через [`/revise`](/ru/care/slash-commands/overview/) — новую версию, а не новую цепочку. |
| Нужна Memory? | Нет. | **Да** (`CARE_MEMORY__BASE_URL`). |

## Ad-Hoc

Быстрый путь. Введите задачу → MAGE генерирует → CARL выполняет → печатается ответ.
Агент может итерировать (ReAct) до завершения; когда несколько шагов успешны, MAESTRO
делает один дополнительный вызов, чтобы синтезировать единый связный ответ. Ad-Hoc хранит
короткую скользящую историю (`CARE_CHAT__AD_HOC_HISTORY_TURNS`, по умолчанию 6), чтобы
у последующих промптов был контекст. `/new` или `/clear` сбрасывает её. Работает без
настроенной Memory.

Используйте для: быстрых ответов, исследования, разовых задач.

## Production

Долговечный путь — для агентов, которые вы будете хранить, измерять и улучшать. Каждый
промпт создаёт одну **воспроизводимую** цепочку (без ReAct, без синтеза), сохраняемую в
Memory. Детали и полный жизненный цикл — на странице [Режим Production](/ru/care/workflows/production/).

Используйте для: агентов, которых вы хотите сохранить, для которых хотите собрать датасет,
эволюционировать и продвигать.

:::note
Production требует `CARE_MEMORY__BASE_URL` (и `CARE_MEMORY__API_KEY`, если развёртывание
требует аутентификации). **Без Memory выбор Production автоматически откатывается к Ad-Hoc**
с предупреждением — тултип переключателя объясняет почему. Задайте стартовый режим через
`CARE_CHAT__DEFAULT_MODE`.
:::
