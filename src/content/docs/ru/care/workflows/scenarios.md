Конкретные сценарии. Сценарии приложения предполагают, что вы прошли
[Быстрый старт](/ru/care/getting-started/quick-start/): модель чата задана, а
для сохранения и эволюции настроены Memory и платформа.

Платные шаги (генерация, запуск, исправление, генерация данных, запуск
эволюции) показывают одно окно подтверждения, если у сессии не режим
**Полный доступ**. Бесплатные шаги (сохранение, переименование, пауза,
отмена) не спрашивают.

## 1. Быстрый ответ с новой цепочкой

1. Новая сессия. Опишите задачу:
   ```text
   Сделай цепочку, которая пересказывает обращение в поддержку одним
   предложением и оценивает срочность от 1 до 5.
   ```
2. Подтвердите генерацию. Посмотрите граф структуры на карточке.
3. Попросите запустить на примере. Подтвердите запуск.
4. Результат не устраивает? Скажите, что изменить: агент сгенерирует заново
   или адаптирует вход. Пока вы не попросите, ничего не сохраняется.

## 2. Оставить то, что работает

1. После удачного запуска скажите «сохрани эту цепочку». Она запишется в
   память новой версией.
2. Откройте **Библиотеку**. Цепочка в разделе **Цепочки**. Если
   сгенерированное название непонятное, переименуйте её там
   (переименование — тоже новая версия).

## 3. Повторно использовать сохранённую цепочку

1. **Библиотека → Цепочки**, откройте цепочку, нажмите **Запустить**.
2. Откроется сессия с готовым запросом. Отправьте его. Агент покажет входной
   контракт и спросит только недостающие данные.
3. Подтвердите запуск.

Или просто попросите в любой сессии: *«запусти цепочку пересказа обращений на
этом тексте: …»*.

## 4. Исправить неудачный запуск

1. Запуск не удался. Попросите «исправь».
2. Подтвердите предложение исправления. Вы получите новую цепочку,
   исходная не изменится.
3. Попросите запустить предложение. Это отдельный запуск со своим
   подтверждением.
4. Если работает, сохраните.

См. [Запуски, пауза и исправление](/ru/care/app/runs/).

## 5. От сохранённой цепочки к проэволюционированной

1. **Данные.** На карточке цепочки нажмите **Данные для эволюции** или
   откройте **Библиотека → Наборы данных**. Задайте число примеров,
   сложность, долю закрытой части и бюджет токенов, запустите. Следите, как
   примеры проходят проверку. Если чего-то не хватает, добавьте инструкции.
   См. [Данные для эволюции](/ru/care/workflows/data-generation/).
2. **Эволюция.** В версии набора нажмите **Использовать для эволюции** или
   на карточке цепочки нажмите **Эволюционировать** и отправьте запрос. Агент
   составит план с оценкой токенов и после вашего подтверждения запустит
   прогон.
3. **Наблюдение.** Следите за панелью прогресса, карточкой эволюции и
   [Активностью](/ru/care/app/activity/). Если IdeaL включён, откройте радар.
4. **Результат.** Попросите результат: лучшая цепочка подготовится в
   сессии. Запустите её на реальном примере, затем сохраните.

См. [Эволюция](/ru/care/workflows/evolution/).

## 6. Наполнить идеи и направить эволюцию (IdeaL)

1. Включите IdeaL в **Настройки → MAESTRO** (память цепочек и пространство),
   перезапустите приложение.
2. **Библиотека → Идеи → Добавить идею.** Опишите конкретное изменение.
   Проверьте похожие идеи, при необходимости переведите на английский,
   сохраните. Можно попросить агента исследовать задачу и предложить идеи:
   он покажет список на проверку до сохранения.
3. Запустите эволюцию. Её мутации получают подборки идей из вашего
   пространства.
4. На радаре подсуньте перспективную идею в следующие мутации идущей
   эволюции.
5. После прогона граф идей покажет, какие идеи помогли. Те, что не
   помогли, отправьте в архив.

См. [Идеи и радар IdeaL](/ru/care/app/ideas/).

## 7. Добавить недостающий инструмент

1. **Библиотека → Инструменты и навыки → Создать инструмент.** Опишите его.
2. Подготовьте черновик. Убедитесь, что запуск на примерах в песочнице
   прошёл.
3. Сохраните. Позже переработайте так же, переработка станет новой версией.

См. [Мастерская инструментов и навыков](/ru/care/workflows/workshop/).

## 8. Долгая работа в фоне

Попросите «запусти эту эволюцию в фоне» (так же для генерации, запуска и
исправления). Задача появится в панели задач и в Активности. Можно дальше
общаться в чате. Завершение задачи останавливает работу. Для эволюции оно
отменяет прогон на платформе.

## Аналоги в TUI

- Быстрые ответы: режим **Interactive**, введите задачу, подтвердите запуск.
  `/new` начинает заново.
- Постоянные цепочки: `/mode production`. Каждый запрос генерирует,
  сохраняет, делает базовый прогон и запускает эволюцию. Следующие запросы
  правят цепочку.
- Наборы данных и эволюция: `/dataset …`, `/evolution …`. См.
  [Режим Production](/ru/care/workflows/production/).
- `@file` прикрепляет файл к задаче.

## CLI и CI

```bash
maestro doctor --no-probes                         # проверка без сети
maestro generate "Triage support tickets" --save triage --output triage.json
maestro validate triage.json                       # разбор + preflight
maestro run <chain_id> --execute --task "Checkout is down for everyone"
maestro search "triage" --search-type hybrid
maestro evolve <chain_id> --wait --accept
```

Отредактировать сохранённую цепочку вручную и импортировать обратно:

```bash
maestro memory show <chain_id> --content-only > chain.json
# правим chain.json
maestro validate chain.json
maestro import chain.json --apply
```

См. [справочник CLI](/ru/care/cli/overview/) и
[Экспорт и импорт](/ru/care/cli/export/).
