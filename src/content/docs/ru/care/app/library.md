Кнопка **Библиотека** в боковой панели открывает всё, что сохранено в памяти
Maestro. Она открывается без сессии и без вызова модели.

## Строка состояния памяти

Вверху панели написано, какую память читает это окно:

- локальная или облачная, и хост;
- пространство IdeaL и число идей в нём, если память цепочек — IdeaL;
- что исправить, если память не отвечает: нет ключа
  (*Настройки → MAESTRO → Memory API key*) или сервер недоступен.

Список ограничен ключом памяти из настроек. Анонимный ключ или ключ с
доступом ко всему может показать данные нескольких пользователей. Панель не
обещает личной изоляции.

## Разделы

| Раздел | Что показывает | Нужна открытая сессия |
| --- | --- | --- |
| **Цепочки** | Сохранённые цепочки с поиском по названию и описанию. | Нет |
| **Карточки памяти** | Сохранённые карточки памяти (заметки, сводки запусков). | Нет |
| **Идеи** | Идеи IdeaL, граф идей, радар прогона. См. [Идеи и радар IdeaL](/ru/care/app/ideas/). | Да |
| **Наборы данных** | Генерации данных для эволюции и версии наборов. См. [Данные для эволюции](/ru/care/workflows/data-generation/). | Да |
| **Инструменты и навыки** | Мастерская: создать или переработать инструмент или навык. См. [Мастерская инструментов и навыков](/ru/care/workflows/workshop/). | Да |

Цепочки и карточки памяти читаются через канал только для чтения, за ним нет
агента. Идеи, наборы данных, инструменты и навыки читаются и меняются *от
имени открытой сессии*: их запись и платные действия идут через путь
подтверждений этой сессии. Без открытой сессии эти разделы об этом сообщат.

В списках по 20 записей на странице. Поиск показывает не больше первых 100
результатов. Чтобы увидеть остальные, уточните запрос.

## Карточка цепочки

Нажмите на цепочку, чтобы открыть её карточку:

- название, описание задачи, число шагов и версия;
- **граф структуры**: названия шагов, типы и зависимости. Промпты и
  настройки шагов не показываются;
- **Переименовать**: сохраняет цепочку под понятным названием как **новую
  версию** той же цепочки. Описание и шаги не меняются. Нужна открытая
  сессия (версия пишется от её имени). Для памяти только для чтения действие
  отклоняется;
- **Эволюции этой цепочки**: прогоны эволюции этой цепочки из IdeaL, новые
  сверху, со статусом, лучшим результатом, числом мутаций и кнопкой радара.
  Прогоны, начатые до того, как у задач появились постоянные ключи, не
  находятся. Пустое состояние об этом говорит.

## Действия открывают черновик, а не запуск

На карточке три кнопки:

- **Запустить**
- **Эволюционировать**
- **Данные для эволюции**

Ни одна из них ничего не запускает из панели. Каждая открывает новую сессию
(или заполняет открытую пустую) с **готовым запросом в поле ввода**. Вы
читаете его, при необходимости правите и отправляете сами. Платные шаги
потом подтверждаются окном приложения, как обычно.

Например, «Эволюционировать» готовит запрос: найти подходящие наборы данных
для этой цепочки, спросить вас, если их несколько, подготовить артефакты,
составить план и запустить эволюцию.

Если рабочая папка ещё не выбрана, панель сначала попросит её выбрать.

## Ограничения

- Списки Библиотеки свежи на момент последнего обновления. Нажмите ↻.
- Поиск по карточкам памяти возвращает не больше 100 результатов.
- В Библиотеке ничего не удаляется. Идеи архивируются, а не удаляются.
