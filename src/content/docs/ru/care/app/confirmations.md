Правило простое: **платная работа спрашивает один раз, бесплатные действия
не спрашивают.** Окно показывает приложение, а не агент. Агенту велено не
спрашивать в чате «продолжать?» перед действием Maestro, а бриф или
уточняющий вопрос в чате подтверждением никогда не считаются.

В окне короткое описание того, что будет, и две кнопки: **«Разрешить один
раз»** и **«Отклонить»**.

## Платная работа: одно окно

Эти действия вызывают модель (или запускают много вызовов):

| Действие | Почему платно |
| --- | --- |
| Генерация цепочки через MAGE | Вызывается модель генерации. |
| Запуск цепочки, в том числе каждый **тестовый прогон**, пока агент пишет цепочку | Шаги цепочки могут вызывать модель и внешние инструменты. |
| Предложение исправления | Один вызов модели, исходная цепочка не меняется. |
| Запуск эволюции | Много вызовов модели в пределах бюджета из плана. |
| Запуск генерации набора данных, запуск или переписывание программы-генератора, догенерация из чата | Вызовы модели в пределах заданного бюджета. См. [студию наборов данных](/ru/care/autobench/overview/). |
| Черновик инструмента или навыка | Один-два вызова модели. Код инструмента запускается только в песочнице. |
| Перевод идеи на английский | Один небольшой вызов модели. |
| Команда CLI с последствиями через мост команд | Команда может писать данные или обращаться к сервисам. |

Работа идёт, только если вы разрешили. Отказ или закрытие окна
останавливают действие до того, как что-либо отправлено. Фоновая задача
тоже спрашивает один раз: разрешение на задачу покрывает вызов внутри неё.

## Смена настроек из чата

*Линия разработки.* Когда вы просите агента поменять настройку Maestro,
приложение показывает окно для этой смены, хотя ничего не платно. Это окно и
есть подтверждение. См. [Настройки из чата](/ru/care/app/chat/#настройки-из-чата).

## Бесплатные действия: без окна Maestro

Эти действия не обращаются к провайдеру модели. Maestro не добавляет для них
окно:

- подготовка входных данных для запуска;
- импорт файла CSV/TSV/XLSX из папки проекта как набора данных для оценки
  (*линия разработки*);
- правка примеров набора данных и сборка версии набора (*линия
  разработки*);
- сохранение цепочки в память (новая версия) и переименование;
- сохранение проверенного инструмента или навыка;
- сохранение идеи и отправка её в архив;
- подсказка идеи в идущую эволюцию и снятие подсказки;
- отмена эволюции;
- пауза, продолжение и остановка идущей цепочки;
- пауза, остановка и дополнительные инструкции для идущей генерации набора
  данных (её бюджет одобрен при старте);
- всё, что только читает: планы, поиск, проверка структуры, чтение
  вложений, чтение настроек, «Мои агенты», статусы, графы.

Остальные инструменты харнесса (файлы, командная строка, веб-страницы и
другие) подчиняются режиму доступа сессии, а не этим правилам.

## «Полный доступ»: не спрашивать никогда

У каждой сессии есть режим доступа. В режиме **«Полный доступ»** сессия
никогда не спрашивает, и платная работа Maestro тоже идёт **без окна**.
Выбор этого режима — ваше постоянное согласие на платную работу в этой
сессии. Включайте его, когда доверяете задаче и бюджету сессии. При
включении приложение попросит подтвердить, что вы понимаете риски.

*Линия разработки.* В прежних сборках этот режим мог вообще блокировать
инструменты Maestro, даже бесплатную подготовку, и агент не мог подготовить
или прогнать цепочку. Теперь инструмент Maestro в «Полном доступе» идёт без
окна, а вызов, который харнесс запрещает, по-прежнему запрещён.

Если приложение не может прочитать настройку подтверждений сессии, платное
действие **отклоняется** с кодом `MAESTRO_APPROVAL_UNAVAILABLE`. Ничего не
запускается. Это не считается вашим отказом.

## Формы Maestro сами считаются согласием

Часть работы начинается из собственных форм Maestro, где вы видите
параметры до нажатия кнопки:

- **«Запустить генерацию»** и действия с генератором в студии наборов
  данных, с бюджетом на экране; догенерация с экрана самого набора (из чата
  она спрашивает);
- **«Подготовить черновик»** и **«Сохранить в память»** в мастерской
  инструментов и навыков.

Нажатие кнопки и есть согласие на этот один вызов. Второго окна нет.

## Чего агент не может

- Ни один инструмент Maestro не принимает от модели флаг «одобрено». Агент не
  может одобрить собственное действие.
- Модель чата не обойдёт окно, переформулировав запрос.
- Агент не может менять API-ключи, блокировку приложения и модель чата.
  Ключи вводятся только в окнах самого приложения.
- Сохранение на [странице настроек MAESTRO](/ru/care/app/settings/) всегда
  просит нативное подтверждение именно этого изменения.

## Известное ограничение

Вызовы из форм распознаются по идентификатору, который ставит форма
приложения. Пока не исключено, что вызов не из формы Maestro может нести такой
идентификатор (например, через свой OpenAI-совместимый адрес, который вы
контролируете). До тех пор работайте с адресами моделей, которым доверяете.
