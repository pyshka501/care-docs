Правило простое: **платная работа спрашивает один раз, бесплатные действия
не спрашивают.** Окно показывает приложение, а не агент. Агенту велено не
спрашивать в чате «продолжить?» перед действием Maestro.

## Платная работа: одно окно

Эти действия вызывают модель (или запускают много вызовов) и показывают
одно окно подтверждения с коротким описанием того, что произойдёт:

| Действие | Почему платно |
| --- | --- |
| Сгенерировать цепочку | Вызывает модель для генерации. |
| Запустить цепочку | Шаги могут вызывать модель и внешние инструменты. |
| Предложить исправление | Один вызов модели; исходная цепочка не меняется. |
| Запустить эволюцию | Много вызовов модели в пределах бюджета из плана. |
| Запустить генерацию данных для эволюции | Вызовы модели чата в пределах заданного бюджета. |
| Подготовить черновик инструмента или навыка | Один-два вызова модели чата; код инструмента запускается только в песочнице. |
| Перевести идею на английский | Один небольшой вызов модели чата. |
| Выполнить команду CLI с эффектами через мост команд | Команда может писать данные или вызывать сервисы. |

Работа продолжается, только если вы её разрешили. Отказ или закрытие окна
останавливают действие до отправки чего-либо. Фоновая задача тоже
спрашивает один раз: согласие на задачу покрывает вызов внутри неё.

## Бесплатные действия: без окна

Эти действия не вызывают провайдера модели и проходят без окна Maestro:

- сохранение цепочки в память (новая версия) и переименование цепочки;
- подготовка входных данных для запуска;
- сохранение проверенного инструмента или навыка;
- сохранение, правка, архивирование и возврат идеи;
- подсказка идеи в идущую эволюцию и её снятие;
- отмена эволюции;
- пауза, продолжение и остановка идущей цепочки;
- пауза, продолжение, остановка, повтор и дополнительные инструкции для идущей
  генерации данных (её бюджет подтверждён при старте);
- всё только для чтения: планы, поиск, Библиотека, статусы, графы.

Другие инструменты харнесса (файлы, оболочка и так далее) следуют
собственным настройкам подтверждений харнесса, а не этим правилам.

## Полный доступ: никогда не спрашивать

У каждой сессии есть режим доступа. В режиме **Полный доступ** сессия никогда
не спрашивает, и платная работа Maestro тоже идёт **без окна**. Выбор этого
режима — ваше постоянное согласие на платную работу в этой сессии.
Пользуйтесь им, если доверяете задаче и бюджету сессии.

Если приложение не может прочитать настройку подтверждений сессии, платное
действие **отклоняется** с кодом `MAESTRO_APPROVAL_UNAVAILABLE`. Ничего не
запускается. Это не считается вашим отказом.

## Формы Maestro считаются согласием

Часть работы начинается из собственных форм Maestro, где вы видите параметры
до нажатия кнопки:

- **Запустить генерацию** в форме данных для эволюции (бюджет токенов на
  экране);
- **Подготовить черновик** и **Сохранить** в мастерской инструментов и
  навыков;
- **Перевести на английский**, **Сохранить идею**, **В архив** и **Вернуть из
  архива** в форме идеи.

Нажатие кнопки — согласие на этот один вызов. Второго окна не будет.

## Чего агент не может

- Ни один инструмент Maestro не принимает от модели флаг «подтверждено».
  Агент не может сам одобрить своё действие.
- Модель чата не может обойти окно, иначе сформулировав запрос.
- Сохранение настроек на [странице MAESTRO](/ru/care/app/settings/) всегда
  требует нативного подтверждения точного изменения.

## Известное ограничение

Вызовы из форм распознаются по идентификатору, который ставит форма
приложения. Пока не исключено, что такой идентификатор может нести вызов не
из формы Maestro (например, через собственный OpenAI-совместимый endpoint,
который вы контролируете). До тех пор используйте приложение с endpoint'ами
моделей, которым доверяете.
