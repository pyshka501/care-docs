Настройки открываются шестерёнкой. Разделы, которые нужны в Maestro:

| Раздел | Что в нём |
| --- | --- |
| **Модель чата** | Провайдеры, ключи и модели для чата. По умолчанию эта же модель работает с цепочками. |
| **Права** | Режим доступа по умолчанию для новых сессий. См. [Подтверждения](/ru/care/app/confirmations/). |
| **MAESTRO** | Кто пишет цепочки, уточнения, модель для цепочек, память и IdeaL, платформа эволюции, блокировка приложения. |
| **Codex** | *Линия разработки.* Вход через подписку ChatGPT. |

## Модель чата

Добавьте провайдера, введите его API-ключ и выберите модели, которые
появятся в выборе модели под полем ввода. Провайдер по умолчанию —
**OpenRouter**, при первом запуске приложение просит его ключ. Пока в
**«Модель для цепочек»** стоит **«Как в чате»** (по умолчанию), модель,
выбранная в чате, пишет, генерирует, запускает и исправляет цепочки этого
чата, работает с наборами данных, черновиками мастерской и переводом идей.
Maestro обращается к ней через приватный локальный мост и никогда не
копирует ключ в свои файлы.

## Codex: подписка ChatGPT

*Линия разработки.* Раздел **Codex** («Codex: подписка ChatGPT») позволяет
работать с моделями OpenAI через подписку ChatGPT Plus или Pro.

1. Нажмите **«Войти через ChatGPT»**. Системный браузер откроет страницу
   входа ChatGPT.
2. Войдите там. Если страница не вернулась в Maestro, вставьте в поле адрес
   из строки браузера или код и нажмите **«Отправить»**.
3. Модели появятся в выборе модели в группе `openai-codex` (если раздел
   так говорит, сначала добавьте провайдера `openai-codex` в **«Модели
   чата»**).

Этот вход отдельный от Codex CLI и его не разлогинивает. Учётные данные
остаются в собственном хранилище харнесса. Работа с цепочками на такой
модели идёт из лимитов подписки. **«Выйти»** удаляет вход. Если раздел пишет,
что вход недоступен в этой сборке, встроенная среда выполнения его не
поддерживает.

## Страница MAESTRO

*Линия разработки.* Страница на русском и называется «Цепочки, память и
эволюция». Редкие параметры спрятаны в свёрнутый блок **«Расширенные»**.

### «Генерация цепочек»

| Поле | Варианты | Что делает |
| --- | --- | --- |
| **«Кто пишет цепочки»** | **«Агент (по умолчанию)»**, **MAGE** | Агент: агент чата пишет, прогоняет и исправляет цепочку. MAGE: генератор собирает её без запуска. См. [Как собирается агент](/ru/care/app/agents/). |
| **«Уточнения перед сборкой»** | **«Ручной: спрашивать недостающее (по умолчанию)»**, **«Автоматический: решать самому»** | Задаёт ли агент вопросы карточками или сам перечисляет допущения. См. [Уточняющие вопросы](/ru/care/app/chat/#уточняющие-вопросы). |
| **«Модель для цепочек»** | **«Как в чате (по умолчанию)»**, **«Своя модель»** | Как в чате: генерация, запуск и исправление цепочек идут на модели чата, отдельный ключ не нужен. Своя модель: на модели ниже, что бы ни было выбрано в чате; тогда появляются поля **«Провайдер»**, **«Адрес»**, **«Модель»** и **«Ключ»**. |
| **«Режим генерации»** | **«Быстрый»**, **«Глубокий»** | Для MAGE. Глубокий дольше и дороже, зато тщательнее проверяет структуру цепочки. |

### «Память и IdeaL»

| Поле | Что делает |
| --- | --- |
| **«Адрес памяти»** | API памяти. Для облачного стенда с `/api`, например `https://…/api`. Вставленный адрес страницы IdeaL обрезается до корня `/api`. Локально по умолчанию `http://localhost:8002`. |
| **«Ключ IdeaL»** | Только показывает, сохранён ли ключ. Ключ вводится один раз, на странице входа в [панели IdeaL](/ru/care/app/ideas/#войти-один-раз). |
| **«Память цепочек»** | **«Поиск по библиотеке»** или **«IdeaL (идеи и обучение на эволюциях)»**. Факты из чата в любом случае остаются в локальной памяти. |
| **«Пространство IdeaL»** | Видно при IdeaL. Латиница, цифры, `.`, `-`, `_`, `:`; регистр важен. Обязательно, если не задан проект. |
| **«Проект IdeaL»** | На стендах с проектами: slug или id проекта. Пусто — автоматически: единственный проект ключа, иначе проект с пространством выше, иначе первый. |

### «Расширенные»

| Группа | Поля |
| --- | --- |
| **«Память»** | **«Только чтение»**: ничего не записывать в эту память (для общих и облачных стендов). Ни цепочек, ни инструментов, ни навыков, ни идей; эволюция идёт без памяти IdeaL. |
| **«Исследование при генерации»** | Провайдер **«Поиск в интернете»** и **«Ключ поиска»**; флажки **«Искать в интернете при генерации»** и **«Искать в памяти при генерации»**. DuckDuckGo работает без ключа. |
| **«Платформа эволюции»** | **«Адрес платформы»** и **«Ключ платформы»**; **модель мутаций** (адрес, модель, ключ) и **модель проверки** (адрес, модель, ключ). Эти модели вызывает сама платформа. |
| **«Запасная модель для эволюции»** | Видна, когда «Модель для цепочек» стоит «Как в чате»: провайдер, адрес, модель, ключ. Платформа берёт её, если модели мутаций и проверки не заданы. На работу с цепочками в приложении она не влияет. |
| **«Блокировка при запуске»** | **«Блокировка приложения»**: **«Выключена»** или **«Только Touch ID»**. Действует со следующего запуска, вход по паролю отключён. Переменная `MAESTRO_APP_LOCK_MODE` (`disabled` или `touch-id`) задаёт блокировку на один запуск, страница тогда показывает, что значение задано переменной. |

### Как работает сохранение

1. Поменяйте поля и нажмите **«Сохранить…»**. Страница покажет список
   **«Что изменится»**.
2. Ключи никогда не вводятся на самой странице. **«Задать»** или
   **«Заменить»** открывает нативное окно для секретного ввода, странице
   достаётся только короткоживущий маркер. **«Удалить сохранённый ключ»**
   стирает ключ.
3. **«Подтвердить»** открывает нативное подтверждение именно этого
   изменения. Без него ничего не сохраняется.
4. После любого сохранения **полностью закройте и снова откройте**
   приложение. Работающий агент держит настройки, загруженные при старте.

Сменить адрес или провайдера поиска, оставив старый ключ, нельзя: замените
или сотрите ключ в том же сохранении, чтобы ключ не уехал молча к другому
провайдеру.

Эти настройки можно прочитать и поменять и через агента в чате (кроме ключей
и блокировки). См. [Настройки из чата](/ru/care/app/chat/#настройки-из-чата).

## Где хранятся ключи

*Линия разработки.* `CARE_SECRET_STORE` выбирает одно хранилище на всё
приложение:

| Значение | Где живут ключи |
| --- | --- |
| `file` (по умолчанию) | Без связки ключей. Настройки MAESTRO пишут значения ключей в `.env` приложения (`~/Documents/Maestro/.env` для собранного приложения) и в `~/.config/care/config.toml`, оба файла доступны только владельцу (`0600`). Ключи модели чата лежат в собственном файле учётных данных харнесса, тоже только для владельца. Системных запросов нет, но эти файлы может прочитать любой процесс под вашим пользователем macOS. |
| `keychain` | Прежнее поведение: в файлах ссылки `keystore://`, а значения в связке ключей macOS. Если ключ туда записать нельзя, сохранение падает, а не пишет ключ открытым текстом. |

Задайте её в оболочке или в `.env` приложения, например
`CARE_SECRET_STORE=keychain`. При первом запуске с `file` приложение
заменяет каждую ссылку `keystore://` в этих двух файлах её значением,
читая каждую запись один раз без окна. Записи в связке ключей не удаляются.
Ссылку, которую прочитать не удалось, приложение стирает с предупреждением,
этот ключ нужно ввести заново в Настройки → MAESTRO. Ключи модели чата,
которые хранил необязательный провайдер связки ключей, не переносятся:
введите их один раз в **«Модели чата»**.

Страница настроек показывает, где лежит сохранённый ключ: «Задан (в файлах
MAESTRO)» или «Задан (в связке ключей)».

Те же настройки можно задать переменными окружения `CARE_*`, см.
[Конфигурацию](/ru/care/configuration/overview/).

## Язык интерфейса

Интерфейс следует языку системы или языку, выбранному в настройках
харнесса. Maestro добавляет в харнесс **русский** языковой пакет: боковая
панель, чат, выбор модели, права и подтверждения, задачи, вопросы,
настройки и другие экраны оболочки (около тысячи строк). Редкие экраны
харнесса остаются на английском.

Собственные панели Maestro («Мои агенты», IdeaL, «Активность», вкладка
«Сессия», карточки результатов, тексты подтверждений) и страница настроек
**MAESTRO** на русском.

Язык ответов цепочек — отдельная настройка для CLI и TUI:
`CARE_DEFAULTS__LANGUAGE` (`en` или `ru`).
