Конфигурация приложения задаётся в двух местах:

- **Настройки → Модель чата** (настройки харнесса): провайдеры, ключи и
  модели для чата. В приложении эта модель выполняет и всю работу Maestro с
  моделью.
- **Настройки → MAESTRO**: собственная конфигурация Maestro (память, IdeaL,
  веб-исследование, платформа эволюции, блокировка приложения).

## Модель чата

Добавьте провайдера, введите его API-ключ и выберите модели для селектора.
Модель, выбранная в чате, используется для генерации, запуска,
исправления, генерации данных, черновиков мастерской и перевода идей в этом
чате. Ключ остаётся внутри харнесса. Maestro обращается к модели через
приватный локальный мост и никогда не пишет ключ в свои файлы.

## Страница MAESTRO

Страница на английском. Её разделы:

| Раздел | Поля | На что влияет в приложении |
| --- | --- | --- |
| **Chain generation** | Provider, Generation mode (`fast`/`deep`), Base URL, Model ID, Generation API key | Действует **Generation mode**. Provider, Base URL, Model ID и ключ приложение **не использует**: генерация идёт через модель чата. Они настраивают CLI, TUI и старый workbench. |
| **Research and Memory** | Memory base URL, Read only, Memory API key, Chain memory (обычная или IdeaL), IdeaL namespace, Web search provider и ключ, Enable web research, Enable memory research | Действуют все. |
| **Platform, evolution and validation** | Platform base URL и ключ, URL/модель/ключ мутации, URL/модель/ключ валидации, upload key | Эволюция идёт на платформе с этими моделями мутации и валидации. Upload key использует `/upload` в TUI. |
| **Unlock on launch** | App lock: Off или Touch ID only | Действует со следующего запуска. |

Заголовок самой страницы говорит, что она задаёт «модель для генерации
цепочек MAESTRO». В приложении это не так: генерация использует модель чата.
Эта формулировка — известная неточность.

Замечания к некоторым полям:

- **Memory base URL**: для облачного хранилища укажите API-префикс, например
  `https://…/api`. Локально по умолчанию `http://localhost:8002`.
- **Read only**: Maestro никогда не пишет в эту память. Нет сохранения
  цепочек, инструментов, навыков и идей, эволюция идёт без памяти IdeaL.
  Подходит для общих и облачных хранилищ, которые вы только просматриваете.
- **Chain memory → IdeaL** требует **IdeaL namespace** (латинские буквы,
  цифры, `.`, `-`, `_`, `:`; регистр важен). См.
  [Идеи и радар IdeaL](/ru/care/app/ideas/).
- **Enable memory research**: перед генерацией найти похожие сохранённые
  цепочки. **Enable web research**: разрешить генерации искать в вебе через
  выбранного провайдера. DuckDuckGo не требует ключа.
- **App lock** можно задать на один запуск переменной окружения
  `MAESTRO_APP_LOCK_MODE` (`disabled` или `touch-id`). Страница тогда покажет,
  что настройка задана окружением. Вход по паролю отключён.

### Как работает сохранение

1. Измените поля и нажмите **Review save**. Страница покажет список
   изменений.
2. Ключи на странице никогда не вводятся. **Replace** открывает нативный
   защищённый диалог macOS, странице достаётся только краткоживущий
   дескриптор. Ключи хранятся в Keychain macOS.
3. **Confirm in native dialog** открывает нативное подтверждение именно этого
   изменения. Без него ничего не сохраняется.
4. После любого сохранения **полностью закройте и откройте** приложение.
   Работающий агент держит настройки, загруженные при старте.

Значения пишутся в `~/.config/care/config.toml` и `.env` проекта. Ключи
хранятся только как ссылки `keystore://` на Keychain. Если хранилище ОС
недоступно, сохранение завершается ошибкой, а не пишет ключ открытым
текстом. Те же настройки задаются переменными окружения `CARE_*`. См.
[Конфигурацию](/ru/care/configuration/overview/).

## Язык интерфейса

Интерфейс следует языку системы или языку, выбранному в настройках
харнесса. Maestro добавляет в харнесс **русский** языковой пакет: боковая
панель, чат, выбор модели, разрешения и подтверждения, задачи, настройки и
другие экраны оболочки (около тысячи строк). Редко используемые экраны
харнесса остаются на английском.

Собственные панели Maestro (Библиотека, Активность, вкладка «Сессия»,
карточки результатов, тексты подтверждений) на русском. Страница настроек
**MAESTRO** только на английском.

Язык ответов цепочек в CLI и TUI задаётся отдельно:
`CARE_DEFAULTS__LANGUAGE` (`en` или `ru`).
