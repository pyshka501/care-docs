**Выпущено**: есть в `mmar-mage` 0.1.3 на PyPI. **Ветка разработки**: версия
пакета 0.2.0, на ветках, на PyPI нет; Maestro закрепляет более старые
ревизии, а кандидат 0.2.0 (`prep/mage-0.2.0`, черновик PR
`Glazkoff/carl-mage#21`) готов к публикации. **Эксперимент**:
исследовательские расширения v3 в `evaluation/` и в модулях, которые
вызываются только оттуда; `MAGEGenerator` их не вызывает, Maestro не
использует.

## Исследовательские расширения v3 (оценочный стенд)

| Возможность | Статус | Код | Замер |
| --- | --- | --- | --- |
| Память генерации (примеры, идеи) | Эксперимент | `mmar_mage/generation_memory.py` | Один раз; без прироста на наборе без повторов. |
| Лестница переиспользования | Эксперимент | `mmar_mage/ideal_loop.py` | Нет. Только офлайн-тесты. |
| Генерация как прогон IdeaL | Эксперимент | `mmar_mage/ideal_loop.py` | Нет. Офлайн-тесты на поддельном сервере. |
| Шаги `code`, которые пишет автор | Эксперимент | `evaluation/codestep_support.py` | Один раз; без прироста. Нужны профиль песочницы и рантайм, которых в пакете нет. |
| Кузница API-инструментов | Эксперимент | `mmar_mage/forge/` | Один раз; насквозь не сработала. |
| Кузница код-инструментов | Эксперимент | `mmar_mage/code_forge.py` | Нет. Только смоук-прогоны. |

К конвейеру v3 они подключаются только через `V3Hooks`, из рукавов
MAGEBench в `evaluation/`. Ветки: генератор v3 на `feat/v3-phase0`; память,
кузница и шаги `code` на `feat/v3-memory`, `feat/v3-forge`,
`feat/v3-codestep`; всё это вместе с циклом и кузницей код-инструментов на
`feat/v3-ideal-loop` (acf7091), которая влита в `prep/mage-0.2.0`.

## Не возможности

Эти названия встречаются в коде или старых документах, но на них нельзя
опереться как на работающие функции:

- Поиск инструментов в интернете внутри `MAGEGenerator`: конвейер поиска
  возможностей есть, но до планировщика доходят только возможности с
  привязкой к рантайму, а путь «найти API и сделать из него инструмент»
  целиком живёт только в экспериментальной кузнице.
- `enable_tool_synthesis`: по умолчанию выключен, не измерялся.
