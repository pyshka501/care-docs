## Как они связаны

**CARE** — пользовательский слой поверх стека из четырёх модулей:

<CardGrid>
	<Card title="MAGE — генерация" icon="seti:python">
		Превращает задачу на естественном языке в CARL-цепочку.
	</Card>
	<Card title="CARL — исполнение" icon="rocket">
		Запускает цепочку: DAG-параллелизм, RAG-контекст, инструменты, память, мульти-агент.
	</Card>
	<Card title="GigaEvo Memory — хранение" icon="document">
		Хранит цепочки, агентов, навыки и историю запусков.
	</Card>
	<Card title="GigaEvo Platform — эволюция" icon="random">
		Запускает генетический поиск по цепочкам и продвигает лучших.
	</Card>
</CardGrid>

Если коротко: **CARL — это движок, CARE — это кабина пилота.** CARL можно использовать
отдельно как библиотеку или управлять всей экосистемой через CARE.
