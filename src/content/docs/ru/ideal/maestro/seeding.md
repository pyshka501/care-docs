Новое пространство пустое, а эволюция выдаёт только то, что есть в озере.
Засев — это набросать несколько точных идей для задачи, убрать дубликаты и
сохранить одобренные. Пять хороших идей полезнее тридцати общих.

Засеять можно тремя способами. Все они пишут обычные активные идеи.

## 1. Попросить агента Maestro

В сессии Maestro опишите, что должна делать цепочка. Например: «засей идеи
для задачи: отвечать на числовые вопросы по финансовым отчётам». Агент
следует встроенным инструкциям по озеру:

1. Спрашивает только недостающее: вход, выход, метрика. Пишет в настроенное
   пространство и никогда не выбирает другое сам.
2. Сначала смотрит в озеро (`maestro_ideal_graph`, `maestro_memory_search`).
   Если есть сохранённая цепочка для этой задачи, опирается на её шаги.
3. Ищет приёмы: в своих знаниях и через веб-поиск, если он доступен. Для
   каждой идеи сохраняет короткий источник.
4. Пишет 5–8 идей. Каждая — одно конкретное изменение. Идеи распределены по
   этапам: вход, поиск, рассуждение, проверка, вывод. Текст по-английски;
   если вы писали по-русски, агент вызывает `maestro_idea_translate`.
5. Прогоняет `maestro_idea_check` для каждого черновика: исправляет ошибки,
   убирает точные дубликаты, а похожие делает явно отличными.
6. Показывает таблицу: название, описание в одну строку, ближайшая
   существующая идея, keep / rewrite / drop, и точные тексты. **Ничего не
   пишется, пока вы не одобрите список**, если только вы сами не попросили
   засеять без проверки.
7. Сохраняет одобренные идеи через `maestro_idea_save` и сообщает, что
   сохранено, а что пропущено.

У новых идей нет опыта. Агент не утверждает, что они работают: это решат
следующие прогоны.

Недостающие детерминированные возможности (арифметика, нормализация дат,
точный поиск) — это инструменты, а не идеи. Настоящие инструменты агент
создаёт в мастерской инструментов: она пишет и проверяет код. Без реализации
агент записывает потребность как идею.

## 2. Веб-интерфейс IdeaL

Откройте вкладку IdeaL, выберите пространство и нажмите **Graph**. В виде
графа можно:

- добавить идею или инструмент вручную;
- сгенерировать кандидатов LLM самого озера (`POST /v1/ideal/seed/propose`).
  Каждый кандидат получает вердикт `keep`, `rewrite` или `drop` с причиной и
  до трёх близких существующих сущностей. Ничего не пишется, пока вы не
  добавите выбранных кандидатов;
- скопировать готовый промпт для внешнего агента, если LLM озера не
  настроена.

Для генерации на сервере нужны `IDEAL_LLM_API_URL`, `IDEAL_LLM_API_KEY` и
модель (`GET /v1/ideal/seed/status` показывает, настроено ли это). Идеи,
добавленные так, получают `origin: skill` или помечаются как добавленные
вручную.

## 3. Навык ideal-seed (любой агент для кода)

В репозитории есть переносимый навык `skills/ideal-seed`: `SKILL.md` и
помощник `scripts/lake.py` на стандартной библиотеке Python. Работающий
сервер тоже отдаёт оба файла:

```text
GET {api}/v1/ideal/skill/SKILL.md
GET {api}/v1/ideal/skill/scripts/lake.py
```

Установите его в агента для кода, который поддерживает навыки, и задайте:

```bash
export IDEAL_API_URL=http://localhost:8000/api
export IDEAL_API_KEY=<ключ>
```

Порядок работы тот же, что у агента Maestro: посмотреть озеро
(`lake.py context --namespace NS --task "..."`), записать кандидатов в
JSON-файл, сверить их с озером, показать список на одобрение и записать.

Внутри Maestro этот навык не используйте: агент Maestro работает своими
инструментами и никогда не держит ключ озера в руках.

## 4. При развёртывании

`IDEAL_SEED_NAMESPACE` в `.env` сервера при каждом запуске
`memory-migrate` кладёт в это пространство 40 встроенных идей и одну
стартовую цепочку (цепочку T2-RAGBench). Уже имеющиеся идеи (тот же хеш
описания) пропускаются. В примере `.env` указано `demo`. Оставьте пустым,
чтобы не засевать.

## Что делает засев хорошим

- Одно изменение на идею, с названным шагом, в 1–3 предложениях.
- `when_to_use` — наблюдаемое условие, а не «всегда».
- Без общих советов («улучшить промпт», «взять модель посильнее»).
- Без ответов из тестовой выборки.
- Без перефразировок идей, которые уже есть в озере.
- Текст по-английски, чтобы поиск его находил.
