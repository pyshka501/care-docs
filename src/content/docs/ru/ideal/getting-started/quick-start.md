Вам нужны доступ к консоли IdeaL и проект вашей организации. Администратор
выдаёт данные для входа и добавляет вас в проект.

## 1. Откройте проект

Войдите в консоль и откройте **Мои проекты**. Выберите проект, с озером
которого хотите работать. На странице **Обзор** видны первые шаги, активные
прогоны, последние результаты, новые идеи и топ задач.

Если нужного проекта нет в списке, попросите администратора добавить вас.

## 2. Подключите агента

Откройте **Подключить агента**. В блоке **Ссылка для агента** появится короткая
временная инструкция для подключения.

1. Скопируйте инструкцию из консоли.
2. Вставьте её в терминал, где работает Codex, Claude Code или OpenCode.
3. Выполните указания, которые появятся в терминале.
4. Вернитесь в консоль и дождитесь агента в списке **Агенты**.

## 3. Выберите режим

Консоль спросит **Как работать с озером?**

| Режим | Поведение |
| --- | --- |
| **Простое использование** | Агент обращается к IdeaL, когда вы явно просите об этом. |
| **Суперсила** | Поддерживаемый плагин напоминает агенту использовать IdeaL на протяжении всей серии улучшений. |

Режим можно поменять позже в списке агентов. После подключения начните новый
разговор, чтобы агент получил актуальный проект и режим.

## 4. Начните работу

Назовите агенту проект и опишите задачу и способ оценки. Например: «Улучши это
решение с озером IdeaL проекта и сразу покажи радар прогона».

Агент проверит озеро, начнёт прогон и покажет ссылку на живую
страницу. За результатом следите в **Прогонах**, содержимое озера смотрите в
**Идеях**.
