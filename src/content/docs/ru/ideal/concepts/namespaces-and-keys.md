**Пространство** (namespace) — одно озеро: набор идей, инструментов,
цепочек и событий прогонов, которые относятся друг к другу. Обычно это одно
пространство на команду, на проект или одноразовое для опытов. Рейтинг
сначала считается внутри пространства, а потом заимствует опыт из других
(см. [Рейтинг](/ru/ideal/concepts/rating/)).

## Что может ключ

У каждого API-ключа есть **владелец** (owner) и необязательный список
дополнительных **пространств**.

| Действие | Разрешено, если |
| --- | --- |
| Читать пространство | Это владелец или пространство из списка ключа, либо у ключа есть `read:any`. |
| Писать в пространство | Это владелец или пространство из списка ключа, либо у ключа есть `write:any`. |
| Писать без указания пространства | Запись идёт в пространство владельца. |
| Получать списки без указания пространства | Только пространство владельца, если у ключа нет `read:any`. |
| Сообщать результаты прогона | Ключ должен иметь право писать во все пространства, где у прогона уже есть события. |

Запрещённое пространство даёт **403** «Namespace is not allowed for this key».
Списки пространств (`/v1/search/facets`, MCP `ideal_namespaces`) показывают
только те, что ключ может читать.

## Права (scopes)

| Право | Даёт |
| --- | --- |
| `read:any` | Чтение всех пространств. |
| `write:any` | Запись во все пространства. |
| `delete:any`, `clear:all` | Разрушительные служебные эндпоинты. |
| `admin:keys` | Admin API и вкладка Admin: выпуск, просмотр, правка и отзыв ключей, переключатель обязательной авторизации. |
| `evolve` | Зарезервировано для клиентов эволюции. |

## Анонимный режим

`AUTH_REQUIRED=false` (по умолчанию) обслуживает запросы без ключа как
анонимные, без ограничений по пространствам. Переданный ключ всё равно
проверяется: неверный, отозванный или просроченный ключ получает 401.

Администратор может переопределить окружение во вкладке Admin
(«Требовать API-ключ»). Это запись `PUT /v1/admin/settings {"auth_required": true}`.
Сохранённое значение важнее `AUTH_REQUIRED`. `GET /health` показывает
текущий режим: `"auth": "open"` или `"required"`.

Руководство для агентов (`/v1/ideal/AGENTS.md`) и файлы навыка засева
доступны без ключа даже в строгом режиме.

## Выпуск ключей

Из командной строки (открытый текст печатается один раз, в базе хранится
только хеш):

```bash
make create-key OWNER=alice [SCOPES=read:any] [LABEL="..."] [EXPIRES_DAYS=30]
```

Эта команда задаёт только владельца и права. Дополнительные пространства
назначаются во вкладке Admin или через `PATCH /v1/admin/keys/{key_id}`.

Во вкладке Admin или через `POST /v1/admin/keys` с `{owner, label,
namespaces, scopes, expires_days}`. Такие ключи также хранятся
зашифрованными на `API_SECRET_KEY`, поэтому администратор может посмотреть
открытый текст позже. Ключи из командной строки посмотреть повторно нельзя.

Вкладка Admin показывает ключи с `last_used_at`, числом запросов и
активностью по пространствам (прогоны, последнее событие). Активность
буферизуется и записывается не чаще раза в минуту на ключ.

:::caution[Bootstrap admin]
Миграция `016` добавляет ключ `bootstrap admin` (владелец `admin`, права
`admin:keys`, `read:any`, `write:any`) по фиксированному хешу из репозитория.
Он нужен, чтобы стенду не требовался доступ к оболочке. На своём развёртывании
отзовите его во вкладке Admin, если вам не передали его открытый текст.
:::

## Подписанные ссылки на прогоны

Страницы прогонов (`/v1/ideal/run/{namespace}/{run_id}?sig=...`) работают без
API-ключей. `sig` — это HMAC от пространства и id прогона на `API_SECRET_KEY`.
Любой, у кого есть ссылка, видит прогон и, пока прогон идёт, может подсовывать
или добавлять в него идеи. Считайте такие ссылки секретом: не пишите их в логи
и не публикуйте. Неверная или пустая подпись даёт 404.

Читатель пространства может получить ссылки любого прогона через
`GET /v1/ideal/run/{namespace}/{run_id}/link`. Так Maestro показывает радар
прогонов, которые запускал не он.

## В Maestro

Maestro читает и пишет ровно одно настроенное пространство (**IdeaL
namespace** в настройках). Другие пространства, доступные ключу, он может
показать, но только для просмотра. Подробнее: [Подключение Maestro](/ru/ideal/maestro/connect/).
