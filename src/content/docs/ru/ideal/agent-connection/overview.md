IdeaL работает с агентами по MCP без сохранения состояния. Откройте
**Подключить агента** в консоли проекта, скопируйте инструкцию и выполните её в
терминале агента. Инструкция подключения персональная.

После настройки начните новый разговор. Сначала агент проверит доступные
проекты и текущий режим, поэтому изменения из консоли применятся без ручной
перенастройки.

## Режимы подключения

| Режим | Когда выбирать |
| --- | --- |
| **Простое использование** | IdeaL нужен только по вашей явной просьбе использовать озеро проекта. |
| **Суперсила** | Поддерживаемый плагин должен удерживать IdeaL в цикле на протяжении всей серии улучшений. |

Режим хранится вместе с подключённым агентом и меняется в его карточке в
консоли.

## MCP-инструменты

Эти инструменты вызывает агент; вручную пользователю они обычно не нужны.

| Инструмент | Назначение |
| --- | --- |
| `ideal_agent` | В начале сессии получить подключённые проекты, режим и актуальные инструкции. |
| `ideal_namespaces` | Показать доступные озёра при ручном подключении вне проекта. |
| `ideal_catalog` | Один раз перед построением прочитать подходящие идеи, инструменты и сохранённые решения. |
| `ideal_start_run` | Начать серию улучшений и получить ссылку на живой радар. |
| `ideal_ideas` | Получить идеи перед одним оцениваемым изменением. |
| `ideal_report_change` | Сообщить результат изменения. |
| `ideal_report_run` | Завершить прогон и сохранить лучшее переиспользуемое решение. |

MCP-сервер также отдаёт полное руководство для агента как
`ideal://AGENTS.md` и сценарий засева как `ideal://skill/SKILL.md`.

## Ожидаемое поведение агента

В подключённом прогоне агент должен:

1. проверить каталог перед первым решением;
2. начать один прогон и сразу показать ссылку на живую страницу;
3. запрашивать идеи перед каждым оцениваемым изменением;
4. сообщать результат каждого изменения;
5. завершить прогон лучшим найденным решением, даже если работа остановилась раньше.
