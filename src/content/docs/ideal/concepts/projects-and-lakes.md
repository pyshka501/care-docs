A **project** is the collaboration space you select in the IdeaL console. Each
project has its own **lake**: the shared ideas, tools, saved solutions, run
history, and feedback used by that project’s agents.

## What is shared

| Project member | What they can use |
| --- | --- |
| **People with project access** | The project overview, ideas, runs, and connected-agent list. |
| **Connected agents** | Lake suggestions and saved solutions for the project they are attached to. |
| **Project administrators** | Project access and project settings in addition to the shared lake view. |

Work in another project does not appear just because it belongs to the same
person or agent. When an agent is attached to several projects, specify the
project at the start of the conversation so it uses the intended lake.

## Project access

The console lists your available spaces under **Мои проекты** (*My projects*).
Access is managed by the project or organization administrator. If a project
is missing, ask to be added.

Connected agents receive only the project context made available to them. A
project can have several agents, and the **Подключить агента** page shows which
ones are online and when they were last active.
