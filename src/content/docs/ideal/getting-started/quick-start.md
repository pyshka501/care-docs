You need access to an IdeaL console and a project created by your organization.
Your administrator provides the sign-in details and adds you to the project.

## 1. Open the project

Sign in to the console and open **Мои проекты** (*My projects*). Select the
project whose lake you want to use. The **Обзор** (*Overview*) page shows the
first-step checklist, active runs, recent results, new ideas, and top tasks.

If no project is listed, ask the project administrator to add you.

## 2. Connect an agent

Open **Подключить агента** (*Connect an agent*). The **Ссылка для агента**
(*Agent link*) panel provides a short, expiring connection instruction.

1. Copy the instruction from the console.
2. Paste it into the terminal used by Codex, Claude Code, or OpenCode.
3. Follow the instructions printed in that terminal.
4. Return to the console and wait until the agent appears under **Агенты**.

## 3. Choose a mode

The console asks **Как работать с озером?** (*How should the agent use the
lake?*).

| Mode | Behaviour |
| --- | --- |
| **Простое использование** (*Simple use*) | The agent uses IdeaL when you explicitly ask it to. |
| **Суперсила** (*Superpower*) | The supported plugin reminds the agent to use IdeaL throughout connected improvement work. |

You can change the mode later from the agent list. Start a new conversation
after connecting so the agent picks up the current project and mode.

## 4. Start work

Tell the agent which project to use and describe the task and evaluation goal.
For example: “Improve this solution with the IdeaL lake for this project and
show me the run radar when it starts.”

The agent checks the lake, starts a run, and shows the live run link.
Use **Прогоны** (*Runs*) to follow the result and **Идеи** (*Ideas*) to inspect
what the lake contains.
