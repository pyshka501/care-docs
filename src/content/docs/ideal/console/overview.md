The IdeaL console is organized around projects. After sign-in, **Мои проекты**
(*My projects*) lists the projects available to you. Select one to open its
lake.

## Project sections

| Section | What it shows |
| --- | --- |
| **Обзор** (*Overview*) | **Первые шаги**, project counts, current runs, recent results, new ideas, and top tasks. |
| **Подключить агента** (*Connect an agent*) | A connection instruction, connected agents, their mode, and online status. |
| **Прогоны** (*Runs*) | Running and finished improvement runs. Open one for progress, helpful ideas, mutations, and the radar. |
| **Идеи** (*Ideas*) | All project ideas in **Список** (*List*) or **Граф** (*Graph*) view, with task, effect, and source filters. |
| **Настройки проекта** (*Project settings*) | Project access controls, visible to project administrators. |

The project switcher in the header moves between lakes. The **RU / EN** switch
changes between the readable Russian view and original data fields; it does
not move work to another project.

## Overview

Use **Обзор** for a quick status check:

- **Первые шаги** — whether an agent, first run, and first ideas are present;
- **В проекте** — runs in progress, idea count, and agents online;
- **Сейчас** — current activity;
- **Последние результаты** — recently completed work;
- **Что нового** — recent lake additions;
- **Топ задач** — recurring tasks and their run history.

## Ideas

Open **Идеи** to search and filter idea cards. **Список** is best for reading;
**Граф** connects ideas with runs, chains, steps, and tools. The effect filters
separate ideas that helped, had no effect, hurt, or have not been evaluated.

**Засеять озеро** (*Seed the lake*) opens two paths: research candidates with
**Своим агентом** (*Your agent*) or propose them **Здесь** (*Here*) when that
option is available. Review the candidate set before adding it.

## Runs

Open **Прогоны**, then select a run. The detail view contains **Динамика**
(*Progress*), **Что помогло** (*What helped*), and **Мутации** (*Mutations*).
**Радар** opens the live run view in a separate tab.
