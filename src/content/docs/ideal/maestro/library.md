Earlier builds of Maestro had an **Ideas** section in the Library with an idea
graph, a memory map and an idea form. In the current development line that
section is gone. Ideas are reached in two ways:

- **The IdeaL panel** in the sidebar shows IdeaL's own pages inside the app:
  the lake radar (*Озеро*), the idea graph (*Граф*) and run pages. You sign in
  there once with your IdeaL key. See [IdeaL panel](/care/app/ideas/).
- **The agent.** Ask in chat to find, add, edit or archive ideas; the agent
  uses Maestro's idea tools, and writes follow the usual
  [confirmations](/care/app/confirmations/).

The panel and the tools work when the chain memory is IdeaL and a namespace or
project is set. See [Connect Maestro to IdeaL](/ideal/maestro/connect/).
